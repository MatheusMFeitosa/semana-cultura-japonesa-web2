# Semana da Cultura Japonesa - Landing Page

Projeto acadêmico desenvolvido para a disciplina de Desenvolvimento Web 2 (IFSP). O objetivo é aplicar conceitos avançados de HTML5 semântico e CSS3 (Tableless, Flexbox, Grid e Responsividade).

## Escolhas do Projeto

*   **Tema:** Um festival gastronômico e cultural fictício focado no conceito de *Omotenashi* (a hospitalidade japonesa).
*   **Design e Cores:** Utilizei o conceito de Wabi-Sabi (minimalismo). A paleta de cores foi construída com variáveis no CSS (`:root`), utilizando tons tradicionais: Fundo Washi (creme), textos Sumi (nanquim), detalhes em Beni (carmim/vermelho) e Matchá (verde).
*   **Tipografia:** Combinação de Noto Serif JP para títulos (trazendo tradição) e Inter para os textos (garantindo legibilidade).

## Requisitos Técnicos Atendidos (Seção 4 do Edital)

### HTML
*   Documento estruturado com tags semânticas: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<figcaption>`, `<footer>`.
*   Hierarquia correta de títulos (h1 a h3).
*   Imagens (JPG/SVG) com o atributo `alt` preenchido para acessibilidade.
*   Incorporação de mídia nativa `<audio>`.
*   Meta tags de SEO configuradas no `<head>`.

### CSS
*   Arquivo externo (`style.css`) importado corretamente.
*   Uso de pseudo-classes (`:hover`, `:nth-child(even)` na tabela) e pseudo-elementos (`::before` nos títulos, `::after` na animação do menu).
*   Layout responsivo *Mobile First* adaptado com `@media queries` para 3 breakpoints (Mobile, Tablet, Desktop).
*   Uso de CSS Grid e Flexbox para diagramação (`tableless`).
*   Demonstração clara do Box Model (`box-sizing: border-box`).
